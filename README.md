## about

I'm **Muhammad Bin Riaz**, a full-stack and AI engineer based in **Islamabad**.

Most of my work sits in one of three places:

1. **Products** — React / Next on the front, Node or Python on the back, Postgres underneath. Auth, dashboards, APIs that agree with the UI.
2. **RAG** — chat and search grounded in *your* documents. Embeddings, retrieval, citations, not a naked LLM wrapper.
3. **Agents** — pipelines that call tools, write back to systems, and keep a human in the loop. Lead routing, research, internal ops.

I take **freelance** work when the brief is scoped and there's a clear owner on your side. Timezone **PKT (UTC+5)** — overlap with EU afternoons and US mornings is usually easy.

## what I actually build

| Area | What “done” looks like |
| --- | --- |
| **Full-stack** | Something you can log into. UI, API, and database that don't fight each other. |
| **RAG** | Answers from your files, with sources. Useful inside a workflow, not a toy chatbot. |
| **Agents** | A loop that calls APIs, writes results, and stops when a human should decide. |
| **Handoff** | A repo you can run, notes on how it works, and a pass so you can keep moving without me. |

I don't take pure visual design with no build, or a 40-service “AI transformation.” I stay in work I can stand behind.
